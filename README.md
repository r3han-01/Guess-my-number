# 🎯 Guess My Number!

An interactive number guessing game built **100% manually from scratch** for frontend revision, enhanced with advanced UI/UX features using **Antigravity**.

🔗 **Live Demo:** [Guess My Number](https://r3han-01.github.io/Guess-my-number/)

---

## 🛠️ Project Origin & Creation

* **100% Manually Built:** Written completely by hand using vanilla web development principles to practice DOM manipulation, state management, and custom CSS without relying on heavy frameworks.
* **Antigravity UI/UX Enhancements:** Polished after initial completion using Antigravity to introduce modern, advanced UI/UX styling and fluid visual effects.

---

## 🚀 Features

* **Dynamic Game Logic:** Generates a random hidden number between 1 and 20 for each game.
* **Real-time Feedback:** Instant visual and text feedback on whether your guess is too high, too low, or correct.
* **High Score Tracking:** Keeps track of your best score across rounds during the active session.
* **Score System:** Start with 20 points; each incorrect guess decreases your score by 1.
* **Responsive & Polished UI:** Modern UI layout with smooth animations and theme transitions upon winning.

---

## 💻 Tech Stack

* **HTML5:** Semantic markup structure built manually.
* **CSS3:** Modern styling, flexbox/grid layout, and custom UI transitions.
* **JavaScript (ES6+):** Pure JavaScript for state handling, game logic, and DOM events.

---

## 🕹️ How to Play

1. **Enter a Number:** Type a guess between **1 and 20** in the input field.
2. **Check:** Click the **Check!** button to test your guess.
   * If your guess is **too high** or **too low**, your score drops by 1.
   * If your guess is **correct**, the background highlights green, revealing the secret number and setting a new high score!
3. **Again!:** Click the **Again!** button at any time to reset the secret number and score while preserving your high score.
